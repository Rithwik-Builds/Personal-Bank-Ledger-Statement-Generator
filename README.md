# Personal Bank Ledger & Statement Generator

## Abstract

The Personal Bank Ledger & Statement Generator is a simple Java-based application used to manage personal bank transactions. It allows users to deposit money, withdraw money, check their balance, and view their banking transactions.

## Advantages

- Easy to use
- Saves time
- Accurate calculations
- Tracks transactions
- Generates statements
- Reduces manual errors
- Easy to maintain

## Implementation

The project is implemented using Java.

### Technologies Used

- Java
- Scanner
- Variables and data types
- Operators
- If-else statements
- Do-while loop
- Methods

### Features

1. Deposit money
2. Withdraw money
3. Check balance
4. Exit the program
